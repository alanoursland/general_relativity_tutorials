# Path: The epistemology path

For readers who want the underdetermination story *above* the physics — the
representation/gauge-freedom argument a strong CS-researcher-type will recognize
immediately, with the GR just as the running example. This path alternates one
physics tutorial with the epistemological lesson it teaches, so the general
point and the concrete instance never drift apart. Physics tutorials not listed
here are linked from these pages as needed but aren't required reading for this
route.

1. [`MAP` — The big picture in one page](../part0-orientation/map.md) — the whole argument spoiled up front: a family, not a metric, and three candidate selectors, only two of which work.
2. [`CORE0` — The four assumptions in common language](../part3-building-the-family/core0-four-assumptions.md) — the specification whose *entire solution set* the book characterizes before asking which member is "the" answer.
3. [`CORE2` — The logarithmic variable and the closure ODE](../part3-building-the-family/core2-log-variable-closure.md) — the key reveal in concrete form: $\lambda$ is a property of which variable you chose to close the flux law in, not a fact about the geometry.
4. [`EPI1` — Representation vs. fact](../part8-synthesis/epi1-representation-vs-fact.md) — the lesson pulled out and named directly: what a coordinate/closure change preserves, and what it doesn't.
5. [`ACC1` — The circularity trap](../part5-energy-accounting/acc1-circularity.md) — a second concrete instance: defining a quantity by reading it off the very equation you're solving for it is circular, for every value of the unknown.
6. [`EPI2` — Identities are not measurements](../part8-synthesis/epi2-identities-not-measurements.md) — the lesson generalized: an identity you can verify by substitution has told you nothing empirical, however physics-flavored its dress.
7. [`PPN3` — $\gamma=1$, $\beta=\lambda+2$](../part6-ppn-observation/ppn3-gamma-beta.md) — the payoff instance: this time the "closure coefficient" *is* tied to an actually measurable quantity — the contrast that makes `EPI2`'s distinction bite.
8. [`EPI3` — Build vs. select](../part8-synthesis/epi3-build-vs-select.md) — the book's central methodological move made explicit: separate what a construction produces from what an added condition selects, and name the smuggled assumption.
9. [`HIST1` — Michell & Laplace: right number, wrong reason](../part7-michell-pg/hist1-michell-laplace.md) — `EPI3` applied to a 240-year-old example: the right numeral, arrived at by an argument that begs exactly the question it looks like it answers.
10. [`SYN1` — A century of shortcuts, mapped](../part8-synthesis/syn1-century-of-shortcuts.md) — the audit run across an entire literature at once: every "simple derivation" of Schwarzschild classified as *build* or *select*.
